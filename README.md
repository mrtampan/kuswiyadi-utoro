# Portofolio Profesional - Kuswiyadi Utoro
**Electrical Engineer & Industrial Electric Mechanic**

Website portofolio dan resume digital yang dirancang khusus untuk melamar pekerjaan. Dibuat dengan HTML5, Vanilla CSS3, dan Vanilla JavaScript modern tanpa dependensi berat, sangat cepat (Lightweight), responsif di HP/Tablet/Desktop, serta langsung siap diunggah ke **Vercel**.

## 🌐 Cara Upload / Deploy ke Vercel

### Opsi 1: Menggunakan GitHub (Paling Direkomendasikan & Gratis)
1. Buat repository baru di akun GitHub Anda (misal: `portofolio-kuswiyadi-utoro`).
2. Upload atau push semua file proyek ini (`index.html`, `style.css`, `script.js`, `vercel.json`) ke repository GitHub tersebut:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Portofolio Kuswiyadi Utoro"
   git branch -M main
   git remote add origin https://github.com/USERNAME-ANDA/NAMA-REPO.git
   git push -u origin main
   ```
3. Buka [https://vercel.com](https://vercel.com) dan login dengan akun GitHub Anda.
4. Klik tombol **"Add New..."** &rarr; **"Project"**.
5. Pilih repository GitHub Anda, lalu klik **"Deploy"**.
6. Selesai! Website langsung aktif dengan domain gratis seperti: `https://portofolio-kuswiyadi-utoro.vercel.app`.

---

### Opsi 2: Menggunakan Vercel CLI (Langsung dari Terminal)
1. Buka PowerShell / Terminal di folder ini (`d:\code\portofolio-toro`).
2. Jalankan perintah:
   ```bash
   npx vercel
   ```
3. Ikuti langkah login di browser dan tekan **Enter** pada semua pilihan default.
4. Website akan langsung terbit dalam hitungan detik.
